# React + ASP.NET User Management System

A full-stack user management project built with **React.js** and **ASP.NET Core Web API**.

## Features

* User Signup & Login
* JWT Authentication
* Protected Routes
* CRUD Operations
* SQL Server Database
* Entity Framework Core
* BCrypt Password Hashing
* Axios API Integration
* Swagger API Testing

## Tech Stack

**Frontend:** React.js, Vite, Axios, React Router
**Backend:** ASP.NET Core Web API, C#
**Database:** SQL Server
**Authentication:** JWT + BCrypt

## How to Run

### Frontend

```bash
npm install
npm run dev
```

### Backend

Open the ASP.NET project in **Visual Studio 2022**, make sure SQL Server is configured, then run the API.

Swagger can be used to test the APIs.

## Project Flow

```text
React Frontend
      ↓
ASP.NET Core API
      ↓
JWT Authentication
      ↓
Entity Framework Core
      ↓
SQL Server
```

## Purpose

This project was created to learn and practice **React frontend development, ASP.NET APIs, authentication, database integration, and CRUD operations**.
